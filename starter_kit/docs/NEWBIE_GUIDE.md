# 零基础新手引导（Bonus +4 素材）

> 目标：一位没有量子背景、甚至不会编程的跨界创作者，5 分钟内靠引导完成
> 第一个量子实验并理解原理。

## 1. 首次运行引导（CLI）

`python3 cli.py --guide` 会先展示 5 分钟引导：

```text

│  🧭 LoomQ 5 分钟新手引导（写给完全没接触过量子的人）            │
│  1. 量子比特（qubit）≈ 一枚"会同时正反旋转的硬币"。           │
│  2. 量子门（gate）≈ 操作这枚硬币的指令，比如 H 让它进入        │
│     50/50 叠加，CX 让两枚硬币"永远同面"（纠缠）。             │
│  3. 你不需要懂数学 —— 只需要用大白话告诉助手你想做什么。       │
│  4. 助手会生成 OpenQASM 2.0 电路，并自动在三家云平台后端      │
│     模拟运行，把结果画成直方图给你看。                        │
└──────────────────────────────────────────────────────────────┘
```

## 2. 量子概念解释（对"人"讲，不对"教科书"讲）

| 概念 | 大白话 | 对应命令 |
|---|---|---|
| 量子比特 | 会同时正反旋转的硬币 | `qinit` |
| 叠加 | 抛硬币瞬间：正反各 50% | `h`（Hadamard） |
| 纠缠 | 两枚硬币从此"永远同面" | `cx`（CNOT） |
| 相位 | 硬币"转速"的快慢 | `rz` / `ry` / `s` / `t` |
| 测量 | 硬币落地，看到正面或反面 | `meas` / `measure` |

详细版见仓库根 `QUANTUM_101.md`（官方速成手册）与本文档。

## 3. 结果可视化

CLI 对每个后端自动输出 ASCII 柱状图：

```text
【braket_local_simulator】engine=sdk
总采样 8192 次
  |000⟩ ████████████████████████  4134 ( 50.5%)
  |111⟩ ████████████████████████  4058 ( 49.5%)
```

- 柱长 = 相对概率，一目了然；
- 三种后端并排展示，用户立刻看到"同一电路、同一结果"——这就是平权。

## 4. 错误恢复与无障碍引导

- 任意输入出错时 CLI 提示"出错了，但别慌：... 换个说法再试，或输入 help"，
  不抛堆栈给用户；
- `help` / `guide` / `clear` / `exit` 常驻；
- LLM 自验失败会明确告诉用户"保真度 0.9x < 0.97，请重新表述需求"，
  而不是交付一个可能错误的电路；
- 后端选型无解时如实说明并给出替代方案（"智能包含知道自己不知道"）。

## 5. 三个示例任务（评测可直接操作）

1. **第一个实验**：输入 `生成一个 2 比特贝尔态并进行全测量` →
   看到 `00`/`11` 各约 50%、且三家平台一致。
2. **错误恢复**：输入 `帮我修复这段代码：H q[0]; CX q[0] q[1]` →
   得到修正后的完整电路并自验通过。
3. **选平台**：输入 `我需要运行一个 15 比特电路，且零排队等待，选哪个平台？` →
   得到规范后端 id 与解释。
